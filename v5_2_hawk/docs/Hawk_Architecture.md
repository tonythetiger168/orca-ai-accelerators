# ORCA v5.2 X++ — Hawk NPU Architecture Specification**Version**: 1.0  **Date**: 2026-09-05  **Target**: High-Performance Edge AI / Light Server / Transformer Inference---## 1. OverviewHawk is the high-performance edge AI accelerator for the ORCA v5.2 X++ series. It bridges the gap between Falcon (4 TOPS) and Phoenix (16 TOPS), delivering **8 TOPS** peak INT8 performance at 2.0 GHz on a 7 nm process. Hawk introduces **Transformer Block Hard-Acceleration** — a dedicated pipeline for LayerNorm, Multi-Head Attention, and Feed-Forward layers that dramatically speeds up LLM and Vision Transformer inference at the edge.---## 2.
